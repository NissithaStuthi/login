# MODULE 7 – SENTIMENT & EMOTION ANALYSIS

## 1. Objective

The objective of this module is to analyze customer complaints and determine customer sentiment and emotional state using NLP-based keyword analysis.

## 2. Dataset

- Total complaints analyzed: 93,280
- Sentiment classes: Positive, Neutral, Negative
- Emotion classes: Anger, Frustration, Disappointment, Fear, Sadness, Satisfaction, Neutral

## 3. Sentiment Distribution

- **Neutral:** 77,521 (83.11%)
- **Negative:** 14,357 (15.39%)
- **Positive:** 1,402 (1.50%)

## 4. Emotion Distribution

- **Neutral:** 75,688 (81.14%)
- **Frustration:** 11,410 (12.23%)
- **Anger:** 3,643 (3.91%)
- **Satisfaction:** 1,576 (1.69%)
- **Fear:** 387 (0.41%)
- **Sadness:** 357 (0.38%)
- **Disappointment:** 219 (0.23%)

## 5. Emotion Intensity

- **Neutral:** 77,521 (83.11%)
- **Very Negative:** 12,422 (13.32%)
- **Negative:** 1,935 (2.07%)
- **Positive:** 1,402 (1.50%)

## 6. Methodology

The complaint text was analyzed using predefined positive, negative, and emotion-related keyword patterns. Each complaint was assigned a sentiment, emotion, and emotion intensity level.

## 7. Output Files

- Sentiment distribution chart
- Emotion distribution chart
- Emotion intensity chart
- Sentiment-emotion cross table
- Module 7 analysis report
